Computer instructions

1. Save the BoostyVP bookmark

You only need to do this once. The bookmark reads your session on Boosty and returns it to your TV.

Replace your old bookmark address with the version from this page: Chrome may have truncated the previous long address.

Drag the BoostyVP button to your browser bookmarks bar. Its name and full address will be saved together.

BoostyVP

Hold the button with your mouse and drag it to the bookmarks bar. In Chrome and Edge, show the bar with Ctrl+Shift+B (on Mac — ⌘Shift+B).

Cannot drag? Add it manually
  1. Press the copy button below, then Ctrl+D (on Mac — ⌘D). Name the bookmark BoostyVP and save it.
  2. Open the new bookmark for editing from the bookmarks menu. Replace the Address / URL field with the complete copied code and save.
Bookmark address for manual copying
  1. Bookmark any page using ⋮ → ★.
  2. Edit the bookmark. Name it BoostyVP and replace its address with the complete copied text.
  3. Return to the open page. Tap the address bar, type BoostyVP and select the suggestion with a star and the javascript: address. Pressing Enter starts a search.

Launch from the address-bar suggestion, not from ⋮ → Bookmarks. Do not open the bookmark in a new tab.

  1. Bookmark any page in your browser. In Safari: Share → Add Bookmark.
  2. Open your bookmarks, hold the saved bookmark and choose Edit.
  3. Name it BoostyVP, replace its address with the copied text and save.
  4. Return to the open page. Open bookmarks and select BoostyVP in this same tab.

Test the saved bookmark

Stay on this page and launch the saved BoostyVP bookmark. Follow the launch instructions above.

Waiting for the bookmark…
I select the bookmark, but nothing happens
  1. Return to the open browser page. Run the bookmark on that page, in the same tab.
  2. Check the saved bookmark address: it must start with javascript:. If it is a website or search-engine address, replace it with the complete copied text.

2. Open Boosty

Sign in as usual, including with Google. After signing in, return here and press the button below again to pass the current connection address.
