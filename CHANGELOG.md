# Изменения

Версия выпуска — дата и номер выпуска за этот день: `2026.10.24.1`, затем
`2026.10.24.2` и т. д. Номер присваивает workflow выпуска, вручную версия не
повышается. Android `versionCode` = `ГГММДДNN`, поэтому каждый следующий выпуск
ставится поверх предыдущего и поверх прежних 0.x. Текст ближайшего выпуска — в
[release-notes/next.md](release-notes/next.md).

## Следующий выпуск

Первый публичный выпуск; ранний pre-release. Готовился под номером 0.0.3, но
опубликован не был — выходит с нумерацией по дате.

- История по аккаунтам, включая досмотренное; меню долгим OK/Menu и запуск сначала.
- Лента «Новое», тексты с изображениями и свёрнутыми комментариями.
- Настраиваемые карточки, подписи, плотность, темы, страница автора и вид плеера.
- Нативный плеер: перемотка, восстановление ссылок/буферизации, качество, скорость по авторам, следующее видео и таймер сна.
- GitHub Pages, документация, сведения о LLM, подписанные архитектурные APK, контрольные суммы и подтверждение происхождения.
- Сервер входа по QR снова запускается на том же порту сразу после закрытия экрана.
- Перед публикацией каждый APK проверяется ClamAV и VirusTotal; отчёты — в описании выпуска и на сайте.
- Сайт показывает только новейший опубликованный выпуск, ссылки берутся из его файлов.
- К выпуску приложен файл происхождения SLSA (`*.intoto.jsonl`).
- Публикация с необычным размером изображения или видео больше не ломает загрузку всей страницы (найдено фаззингом).

Ранние локальные сборки назывались 0.2.0/0.2.1 (`versionCode` 6) и 0.0.3 (7) —
исторические внутренние названия. Код новых версий выше, обновление поверх сохраняется.
