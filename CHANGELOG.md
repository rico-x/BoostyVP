# Изменения

## 0.0.3 — 2026-10-23

Первая консолидированная версия новой публичной нумерации; ранний pre-release.

- История по аккаунтам, включая досмотренное; меню долгим OK/Menu и запуск сначала.
- Лента «Новое», тексты с изображениями и свёрнутыми комментариями.
- Настраиваемые карточки, подписи, плотность, темы, страница автора и вид плеера.
- Нативный плеер: перемотка, восстановление ссылок/буферизации, качество, скорость по авторам, следующее видео и таймер сна.
- GitHub Pages, документация, сведения о LLM, подписанные архитектурные APK, контрольные суммы и подтверждение происхождения.

Ранние локальные итерации назывались 0.2.0/0.2.1 — это исторические внутренние названия. Для 0.0.3 Android `versionCode=7` выше прежнего 6: обновление поверх остаётся возможным.
