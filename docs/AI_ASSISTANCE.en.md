# LLM involvement in development

[Русский](AI_ASSISTANCE.md) · [Documentation](README.en.md)

LLM assistants help prepare BoostyVP code, tests, documentation and infrastructure.
Rico-X sets direction and authorizes publication. Generated-code share is not
measured; the project claims neither entirely manual authorship nor AI-certified
absence of defects.

The app has no LLM integration and sends no viewing history or video to a model.
Development assistance is not a runtime service feature.

Changes undergo available automated checks. TV focus, remote, player and migration
checks require owner authorization. Actual results, skips and test boundaries
are recorded. This is not an independent audit.

When using LLMs:

- Use synthetic tokens/responses; do not share others' passwords, sessions,
  private posts, media URLs or keys.
- Verify APIs/behavior against code and the target Android TV.
- Preserve licenses/authorship; generation grants no relicensing rights.
- Disclose substantial assistance in PRs and list actual checks. Another agent
  or model is not an independent audit.

The contributor proposing a change is responsible for verifying results and rights.
