## Оставшиеся границы проверки

Android 6–13, другие ТВ/ABI и устройства с 16-KiB страницами памяти отдельно
не проверялись. Для B2 подтверждены 35 секунд фона и автоматический возврат
открытого плеера после завершения процесса; отдельная Activity recreation
и часы ожидания не проверены. Дополнительные реальные страницы комментариев
не понадобились; их логика проверена синтетически. Публичного APK для полного
пути обновления пока нет. Это известные границы, а не выданные за PASS проверки.
