## Русский

Комплект от **2026-10-25**: 12 экранов × 2 языка, WebP 1920×1080, качество 85,
метаданные удалены. Старый набор из семи изображений заменён целиком.
Пиксели интерфейса не дорисовывались: PNG сняты на TCL / Android 14.

Home, New, автор, избранное, плеер, настройки плеера, выделение, меню,
приватность, комментарии и экспорт — установленный BoostyVP **2026.10.25.1**,
база кода `e4de85d`. Некоторые RU-кадры взяты из приёмки этой же .1 в тот же
день после проверки соответствия экрану. Английские названия публикаций не
подставляются: пользовательский контент остаётся на исходном языке.

**Next-up — отдельный демонстрационный кадр.** Настоящий текущий NextUpOverlay
снят на ТВ через изолированный DocumentationCaptureTest с вымышленным названием
и плеером без сети/аккаунта. Это не снимок реальной следующей публикации.
Метод позволяет обновлять иллюстрацию без перемотки роликов владельца.

Владелец разрешил показывать живые подписки в документации. Собственный профиль,
телефон/e-mail, токены, QR/адрес входа и медиассылки исключены. Обложки, названия,
видеокадры и комментарии сохраняют права их авторов и не становятся MIT-материалами.
После съёмки возвращён русский интерфейс, каталог и остановленное видео;
показанная сохранённая точка ролика — около 01:33, без перемотки.

[manifest.json](manifest.json) фиксирует язык, источник, размер, байты и SHA-256
каждого WebP, а также SHA-256 исходного PNG. Исходные PNG/служебные логи вне Git.
[Процесс повторной съёмки](../DEVELOPMENT.md#скриншоты).

## English

Captured **2026-10-25**: 12 screens × 2 languages, 1920×1080 WebP, quality 85,
metadata removed. The previous seven-image set was fully replaced. UI pixels
were not redrawn; PNGs were captured on a TCL / Android 14 TV.

Home, New, creator, favorites, player, player settings, focus, menu, privacy,
comments and export show installed BoostyVP **2026.10.25.1**, base `e4de85d`.
Some RU images reuse the same day's acceptance captures of that exact .1 after
screen review. User post titles/content remain in their original language.

**Next-up uses demonstration data.** The actual current NextUpOverlay was captured
on the TV through isolated DocumentationCaptureTest, using a synthetic title/player
without network/account access. It is not a real next publication. This avoids
seeking through the owner's videos solely to capture an illustration.

The owner authorized live-subscription documentation screenshots. Owner profile,
phone/email, tokens, pairing QR/address and media URLs are excluded. Publication
artwork/titles/video frames/comments retain their creators' rights, not MIT.
After capture the app returned to Russian/catalog with playback stopped; the
shown saved point remained around 01:33, without seeking.

[manifest.json](manifest.json) records locale, origin, dimensions, bytes and each
WebP's SHA-256 plus original PNG SHA-256. Raw PNGs/operational logs stay outside Git.
See [capture procedure](../DEVELOPMENT.en.md#screenshots).
