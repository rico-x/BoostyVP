# Roadmap BoostyVP

[English](ROADMAP.en.md) · [Документация](README.md)

Актуализировано 2026-10-25 для кода `e4de85d`, перенесённого в локальный `main`.
Статус «готово» означает наличие в коде и описанные проверки, а не публикацию APK.
Старые поэтапные записи сохранены в [истории](ROADMAP.history.md).

## Реализовано

| Группа | Готовые возможности |
|---|---|
| Вход | Браузерная закладка/QR в LAN, телефон и код; повторное открытие сервера входа |
| Каталог | Подписки по авторам, «Новое» с пагинацией, страницы авторов, фильтры и сортировки, поиск по загруженным метаданным |
| Библиотека | История, позиции, «Смотреть позже», избранные авторы и видео, ручные/автоматические отметки; изоляция по аккаунтам, Room v4 |
| Приватность | Независимые переключатели записи, подтверждаемая очистка выбранных групп текущего аккаунта |
| Публикации | Подробная карточка, текст/изображения, комментарии/ответы только для чтения; комментарии к видео открываются без воспроизведения |
| Плеер | Media3, ускоренная перемотка, качество, скорость по автору, восстановление ссылок, таймер сна, действие в конце, потоковая статистика |
| S7–S10 | CH±/FF/REW/цифры с настройками, двойное «Назад», геометрия видео, INFO/«Поток» |

| V0–V7, V9–V12 | Размеры карточек и текста, подписи, плотность, выделение, полное название, шапка автора, темы/акценты, вид плеера |
| Меню и язык | Ширина/плотность/шрифт/порядок/видимость разделов, сворачивание; самостоятельные RU/EN-пакеты |
| D1 / D4 | Совместимое обновление зависимостей с minSdk 23; неиспользуемый HTTP logging удалён |

| Q2 | Обновление из публичного выпуска | Сквозной сценарий с настоящим выпущенным APK и сохранением данных; синтетическая проверка не заменяет его |
| D2 | Выполнение UI/пульт-тестов в CI | Сейчас APK тестов только компилируются. Эмуляторы — отдельная задача |
| D3 | Модульное покрытие blog/model/home | Дополнительные состояния, ошибки, модели; по отдельному указанию владельца |
| D1, внешний этап | Включить Dependabot version updates на форке | На 2026-10-25 переключатель выключен; совместить с разрешённой публикацией актуального каталога и проверить журнал бота |
| E1 | Разрешение ARDcode на MIT для унаследованного кода | Внешний вопрос; [issue #1](https://github.com/ARDcode/boosty-tv-app/issues/1) без ответа на 2026-10-25 |

Технический долг не становится текущей работой без отдельного указания.
Порядок следующих задач определяет владелец; таблица не задаёт сроки.
Перед публикацией также требуется согласовать отдельный коммит `origin/main`
с проверенной локальной веткой: [готовность к выпуску](RELEASE_READINESS.md).

## Зависит от возможностей сервиса и устройства

- C1: глобальный поиск Boosty — нужен подтверждённый API; локальный поиск уже есть.
- C2: облачная синхронизация библиотеки — нужен подтверждённый протокол и правила данных.
- C3: live — нужны эталонные трансляции и поддерживаемый протокол; чат не включён.
- C4: AFR — только при доступном тестовом ТВ с несколькими режимами.

### Когда-нибудь

**S13: превью кадров на шкале** отложено на неопределённый срок, без планов
и сроков. В проверенной выборке Boosty не предоставил storyboard/image tracks;
это не доказывает отсутствие таких данных у всех публикаций.

### Исключено владельцем

V8 (новые режимы рядов), SponsorBlock, DeArrow, YouTube-рекомендации,
усиление браузерного LAN-сопряжения и изменение fallback при сбое Keystore.
Они не перечисляются как обязательные незавершённые функции. Известные
ограничения хранения/HTTP остаются в [SECURITY](../SECURITY.md).

## Процесс, качество и безопасность

Разработка и история локальные; push/PR/выпуск — по явному запросу владельца.
Обычный процесс `main`: PR, обязательные проверки, squash merge.
Отдельное явное указание владельца может разрешить локальный перенос.
Правила: [AGENTS](../AGENTS.md), [разработка](DEVELOPMENT.md), [публикация](RELEASING.md).

Пульт, фокус, библиотека и миграции проверяются на отдельном debug-пакете;
подписанный release обновляется тем же пакетом/ключом без очистки данных.
Реальная проверка на ТВ выполняется только с разрешения владельца.
Не выдавать компиляцию instrumentation APK за выполненный тест, синтетический
ответ API — за живой сервис, один TCL — за всю матрицу Android.
Исторические отчёты не переписываются под новые результаты.
