# Данные и приватность

[English](PRIVACY.en.md) · [Документация](README.md)

Описание текущего кода на 2026-10-25, не обещание анонимности и не независимый аудит.

## Сеть

Boosty и CDN публикаций получают обычные данные запросов: IP, параметры,
необходимый токен для API. Запрашиваются вход/refresh, подписки, метаданные,
тексты, комментарии, изображения и видео. Номер/код или переданная браузером
сессия нужны сервису, а не разработчику форка.

Собственного сервера рекламы, аналитики, телеметрии или сбора истории нет.
Содержимое просмотра не отправляется в LLM; участие LLM относится к разработке.
Правила Boosty, CDN, Android и лаунчера определяются их владельцами.

Ручная проверка обновлений обращается к GitHub API/файлам `rico-x/BoostyVP`.
GitHub получает сетевые данные запроса, но не сессию Boosty. В APK нет секретов
GitHub; автоматической установки/скачивания нет.

## На телевизоре

| Данные | Хранение и назначение |
|---|---|
| Сессия/устройство/срок токенов | Обычно Keystore/EncryptedSharedPreferences; менее защищённый fallback при сбое описан в SECURITY |
| История и позиции | Room `library.db` v4, отдельно по аккаунтам: ID, автор, название, обложка, точка и время просмотра |
| Закладки и отметки | «Смотреть позже», избранные авторы/видео, просмотренное; метаданные, не скачанные ролики |
| Настройки и изображения | Предпочтения интерфейса/плеера, скорости авторов, обычный кеш изображений |
| Поиск/очередь | До 600 метаданных / 100 видео в памяти сеанса; очищаются при смене аккаунта/завершении процесса |

База и индекс не хранят полные тексты или подписанные видеоссылки. Открытые
публикации, комментарии и ссылки находятся в памяти, пока используются для
загрузки/воспроизведения. Это не означает отсутствия всех сетевых кешей ОС.
Миграция v3 → v4 добавила избранные видео без удаления прежних данных.

Три независимые настройки выключают запись истории, позиций и автоматических
отметок. Выключение не удаляет старое. «Библиотека и приватность» с подтверждением
удаляет выбранные группы **текущего аккаунта**. Вход, другие аккаунты и серверные
подписки не меняются. Удаление одной записи истории не удаляет позицию.

Выход очищает сессию, а не все локальные данные. Полная очистка средствами
Android удаляет вход, библиотеку, кеши и настройки. Системный Android backup
отключён (`allowBackup=false`).

## Данные для системы и лаунчера

По умолчанию канал «Новое» передаёт лаунчеру названия, обложки, авторов и ссылки
открытия доступных видео. Каналы/источники/число карточек настраиваются;
Watch Next для продолжения выключен по умолчанию. Выход/смена аккаунта очищает
карточки этого приложения. Токены и подписанные медиассылки туда не передаются.

Открытый плеер передаёт Android MediaSession название/автора, состояние,
позицию и команды управления. Закрытие освобождает сессию; фонового плеера нет.

## Сопряжение, экспорт и сайт

Браузер передаёт сессию напрямую ТВ по LAN. Временный HTTP-сервер останавливается
после успешного входа или выхода из экрана. AES-GCM-конверт не защищает от всех
атак на HTTP-страницу/доступный в LAN ключ: [SECURITY](../SECURITY.md).

Экспорт JSON содержит только разрешённые настройки плеера/интерфейса/каналов,
без входа, токенов, библиотеки, позиций и скоростей авторов. Для файлового
менеджера создаётся отдельная неизменяемая копия в частном кеше с временным
доступом на чтение. Сохранённый пользователем файл во внешней папке не удаляется
автоматически при очистке библиотеки.

Альтернативная HTTP-страница переноса настроек запускается пользователем
на срок до 10 мин, закрывается при уходе из раздела/в фон; применение импорта
подтверждается на ТВ. Используйте доверенную LAN, не публикуйте адрес/QR.
Этот механизм не изменяет протокол браузерного входа.

GitHub Pages — статическая документация без форм входа, трекеров и удалённых
шрифтов проекта. GitHub обрабатывает данные по своим правилам. Не вводите
на сайте проекта пароль, телефон или токены и не прикладывайте их к Issues.
