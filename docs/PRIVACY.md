# Данные и приватность

Актуально для BoostyVP 0.0.3. Это описание поведения, не обещание анонимности или независимый аудит.

## Сеть

Приложение обращается к Boosty и серверам/CDN публикаций для входа, обновления сессии, подписок, текстов, изображений, комментариев и видео. Сервис получает обычные сетевые данные (например, IP), токен и параметры запросов. Для входа используются номер телефона/код либо переданная из браузера сессия. Это данные для сервиса, не разработчика форка.

Своего сервера сбора данных, рекламы, аналитики, телеметрии и отправки содержимого в LLM в текущем приложении нет. Помощь LLM при разработке не означает использование модели во время просмотра. Правила сервиса и ОС определяются их владельцами.

## Локальное хранение

- Сессия, идентификатор устройства и срок действия токенов. Обычно шифруются Android Keystore/EncryptedSharedPreferences, но при ошибке есть менее защищённый fallback: [SECURITY.md](../SECURITY.md).
- Ключ аккаунта, позиции и история, раздельно по аккаунтам. В базе — ID публикации/видео, автор, название, обложка, позиция и время просмотра; не полные тексты или подписанные ссылки на видео.
- Настройки интерфейса/плеера, скорость по авторам и обычный кеш изображений.

История не синхронизируется с облаком проекта. Выход очищает сессию, но не обещает удаления всей истории, кешей и настроек. «Убрать из истории» не удаляет позицию продолжения. Полное удаление локальных данных — очистка данных приложения в Android или удаление приложения; затем вход/настройки потребуются заново. Системное резервное копирование Android отключено (`allowBackup=false`).

## Подключение и сайт

При входе через QR браузер передаёт сессию напрямую на ТВ в LAN. Временный HTTP-сервер останавливается после успеха или выхода из экрана. Используйте доверенную сеть: шифрование конверта не защищает от всех атак на HTTP-страницу и доступный в LAN ключ.

GitHub Pages — статическая документация без формы входа, трекеров, удалённых шрифтов и аналитики проекта. GitHub обрабатывает данные сайта, Issues, Releases и Actions по своим правилам. На сайте проекта не нужно вводить пароль, номер телефона или токены. Не прикладывайте данные аккаунта, QR и приватные видео к Issues.
