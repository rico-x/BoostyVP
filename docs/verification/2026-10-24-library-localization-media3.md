## Статус

**Проверено локально и установлено на ТВ.** Модульные проверки, debug/release,
`lintVitalRelease`, инструментальные сценарии и проверка реального аккаунта
завершены. Перед тестами владелец получил уведомление и подтвердил готовность.
Вход, библиотека и настройки сохранены; в конце оставлены русский интерфейс

подтверждение работы на всех поддерживаемых устройствах.

## Объём

- Избранные видео независимо от «Смотреть позже» и избранных авторов;
  метаданные по аккаунтам, повторная проверка доступа при открытии.
- `library.db` v4: новая таблица, миграция 3 → 4; цепочки 1 → 4 и 2 → 4
  сохраняются. Никакой деструктивной миграции и очистки пользовательской базы.
- Независимая запись истории/позиций/автоматических отметок по аккаунтам;
  подтверждаемая очистка шести выбранных групп только текущего аккаунта.
  Смена аккаунта между подтверждением и действием проверяется репозиторием.
- Подробности публикации с обновлением данных, доступностью, описанием,
  датой/длительностью/разрешением при наличии и действиями с пульта.
- Порядок/видимость разделов, четыре плотности меню, текст 12–18 sp,
  ширина 192/224/256 dp. «Подписки»/«Настройки» нельзя скрыть.
  Высоты пунктов 32/34/46/54 dp действительно отличаются; длинный текст может
  увеличить пункт по высоте. Плотность не ограничена штатным минимумом 40 dp.
- Отдельные `localization/ru`, `localization/en`, общий типизированный API и
  выбор системного/RU/EN языка. 504 сообщения; браузерные HTML/JS перенесены
  в языковые модули. Тексты авторов не переводятся.
- Media3 1.5.1 → 1.11.1. Требуемый compile SDK 36 и AGP 8.13.2, без AGP 9;
  min SDK 23 и target SDK 35 не изменены. Kotlin/KSP/Compose не обновлялись.
  Размер цифр перемотки больше не зависит от приватного ресурса Media3.

## Локальные результаты

- 238 модульных сценариев Android/JVM: 0 ошибок, 0 пропусков. Включены три
  проверки полноты/форматирования языков, четыре меню/динамических подписей
  и новый сценарий избранных видео.
- 17 проверок инструментов выпуска/Pages: без ошибок; реальные APK не
  отправлялись в VirusTotal, облачные workflow не запускались.
- Отдельная офлайн-проверка браузерного входа прошла для RU/EN: шифрованная
  вымышленная сессия, возврат, отбрасывание внешнего адреса/чужого фрагмента,
  локальная проверка закладки. Логика JS одинакова, различаются сообщения.
- Собраны debug/release и инструментальные APK. Итоговая повторная сборка
  после исправления значков Media3 завершилась за 3 минуты в локальном Docker.
- Экспортированные схемы проверены сравнением: все пять прежних таблиц v3
  неизменны; v4 добавляет только `favorite_posts`. Цепочки миграций дополнительно
  выполнены на настоящем Android SQLite, с вымышленными данными двух аккаунтов.
- Проверка миграции исходных строк не находит русского UI-текста в Kotlin
  вне языковых пакетов. Оставшиеся русские слова в основном коде — комментарии.

Первые прогоны нашли ожидания русского языка в старых JVM-тестах и старую
фиксированную ширину меню. Тесты привязаны к явно выбранному языку и новой
настраиваемой ширине; итоговый прогон прошёл.

### Что выявила проверка внешнего вида

1. Внутренняя строка стандартной TV-кнопки ограничивала минимум 40 dp:
   два плотных режима получались одинаковыми. Боковое меню использует ту же
   штатную TV Surface и обработку пульта с собственной минимальной высотой.
   Добавлена проверка реальной высоты и переноса текста; в компактном режиме
   на ТВ целиком видны все пункты, включая «Настройки».
2. Media3 1.11 перенесла стрелки перемотки из foreground в background кнопки;
   оформление фокуса заменяло их. Штатный drawable сохраняется в foreground,
   без ссылки на приватные ресурсы. Новый тест видимого содержимого значка
   воспроизвёл ошибку до исправления и прошёл после него. Полный повтор
   плеера и снимок реального видео подтвердили стрелки и центрирование цифр.
