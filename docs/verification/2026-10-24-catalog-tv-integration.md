## Что покрывают проверки

### Загрузка и каталог

- Готовые авторы публикуются поэтапно; максимум четыре запроса одновременно.
  Порядок подписок стабилен, медленный первый автор не задерживает других.
- Контролируемое время: первый результат через 50 мс, самый медленный через
  1000 мс. Это виртуальный тест, не замер сети/производительности реального ТВ.
- Частичная ошибка остаётся именованным рядом с повтором. Общая ошибка
  обновления не удаляет видимые карточки; новый refresh отменяет старый повтор.
- Метаданные ограничены 600 карточками и аккаунтом; подписанные источники видео,
  тела публикаций и токены в индекс не попадают. Старый результат другого
  аккаунта отвергается. Coil и существующие Paging-кеши не заменялись.
- Поиск, все слова, выбор автора, видео/текст, доступность, три сортировки;
  открытие карточки и возврат фокуса. Охват ограничен загруженными данными,
  не заявляется поиск по всему Boosty или всей истории подписок.

### Очередь и настройки

- До 100 видеокарточек, дедупликация, перестановка, удаление, очистка и смена
  аккаунта; переход после середины/конца не возвращает к пропущенным элементам.
- Очередь хранится только в сеансе; выбор по-прежнему получает публикацию
  заново. Для предложения следующего используется прежний отменяемый нативный
  отсчёт S3; CH±/FF/REW сохраняют ранее согласованное поведение S7.
- Общий раздел настроек, возврат к плееру/интерфейсу, параметры каналов.
- Экспорт/импорт и сброс только allowlist-полей трёх файлов preferences;
  неизвестные ключи, типы/формат отвергаются до записи. Сентинел неизвестного
  ключа сохраняется, библиотека/аккаунт не затрагиваются.
- Временный LAN-сервер: страница, скачивание, передача валидируемого файла,
  отказ некорректному файлу, отсутствие CORS, `no-store`, остановка. Сам импорт
  требует отдельного подтверждения на ТВ. На устройстве DocumentsUI отсутствует;
  обычный системный файловый диалог на этом ТВ не проверялся.

### MediaSession, каналы и обновления

- Настоящее проигрывание H.264 через MediaController: метаданные, пауза,
  продолжение, seek, отключение контроллера после release сессии.
- Default: ровно один «Новое», Watch Next выключен. Число/содержимое каналов
  сохраняются; источники меняются местами без дублирования.
- Запись в настоящий TV Provider, повторное обновление без дублей; очищение
  карточек при выходе/смене аккаунта. Сетевая ошибка сохраняет карточки только
  прежнего аккаунта и источника, не переносит их под новое название.
- Ссылки с кодированием аргументов; открытие после завершения входа ровно один
  раз, без потери перехода из-за последующего открытия Home.
- Обновлятор: полный разбор синтетического выпуска/manifest, загрузка APK,
  размер/SHA-256 и настоящий PackageManager. Синтетический APK повышенной
  версии с тем же debug-ключом принят; повреждение, другой сертификат,
  несоответствующая версия и понижение отвергнуты. Тестовые APK не установлены.
- GitHub Releases на момент проверки возвращает пустой список. Реальное
  скачивание нового публичного релиза не проверялось: выпуск не создавался
  ради теста. Проверка не содержит секретов GitHub и не публикует артефакты.

## Границы

- Минимум Android приложения 6; каналы доступны с Android TV 8. На других ОС
  поведение лаунчера/разрешений может отличаться. MediaSession только при
  открытом плеере, не фоновое проигрывание; голос/телефон зависят от клиента ОС.
- «Новое»: максимум пять страниц на обновление; избранные — до 20 авторов,
  четыре запроса одновременно. В канале может быть меньше заданного лимита.
- Фоновое расписание настроено примерно раз в час при сети и сохраняется для
  перезапуска ОС; ожидание полного часа и перезагрузка реального ТВ не проводились.
- Очередь и поиск не синхронизируются с другими устройствами и не переживают
  завершение процесса. Перенос настроек не является переносом истории/входа.
- LAN-перенос использует HTTP в доверенной сети и закрывается через десять минут,
  при уходе с экрана/в фон. Это отдельная функция, не изменение сопряжения входа.
- Настройки изображения, технический долг, браузерное сопряжение, S13 и V8
  не изменялись. SponsorBlock и подобные неподдерживаемые интеграции не добавлены.
