## Реализованные изменения

- **B1:** раскрытая панель резервирует фактическую ширину 192/224/256 dp;
  свёрнутая — 112 dp. Общая область всех разделов Home перестраивается,
  сохраняя существующие состояния списков, ключи карточек и маршруты фокуса.
  Обновлён прежний тест, который требовал неизменного viewport/наложения.
- **B2:** текущая сессия хранит точную позицию и намерение воспроизведения.
  ON_PAUSE/ON_STOP фиксируют её перед автоматической паузой, повторное событие
  не заменяет исходное состояние ложным «уже было на паузе». Повторная
  композиция/Activity не загружает снова исходные аргументы после autoplay;
  новая внешняя ссылка при этом действительно открывает новое видео.
  SavedStateHandle восстанавливает именно текущую публикацию и короткую/
  близкую к концу позицию без эвристики «начать заново». URL и токены туда
  не записываются; при выключенной записи позиций остаётся только живая память.
  Финальные записи переживают закрытие ViewModel и выполняются последовательно;
  старый экземпляр плеера не затирает явный перезапуск того же видео.
- **B3:** проверены непосредственные onChange/save пути интерфейса, размера
  карточек, меню, языка, TV-каналов и параметров плеера. Запись обычных
  предпочтений уже выполнялась через apply при изменении; не вводится
  подтверждение или блокирующий commit. В трёх окнах «Готово» заменено на
  «Закрыть», подсказка поясняет немедленное сохранение. Добавлен сценарий
  исчезновения окна без нажатия кнопки закрытия. Подтверждения очистки,
  сброса и импорта сохраняются.
- **B4:** реальная PostCard в предпросмотре чередует обычное и выделенное
  состояния; рамка и увеличение используют те же 120 ms/snap, что карточки
  каталога. Анимация рамки демонстрируется и при отключённом увеличении.
  Показаны масштаб 100→102%/100→100%, длительность 120/0 ms, цвет и толщина.
  Пример не принимает фокус; демонстрационные подписи обновляются при смене
  RU/EN, не фиксируются на языке первой инициализации файла.
- **D1:** [аудит и решения по зависимостям](../DEPENDENCIES.md). Неподходящие
  SDK 37/AGP 9/Kotlin 2.4 версии выявлены AAR/POM и реальной сборкой;
  выбраны совместимые, без повышения minSdk/targetSdk. Сохранено соблюдение
  HTTP Cache-Control для изображений после Coil 3. Локально подготовлено
  еженедельное расписание Dependabot; в GitHub оно ещё не опубликовано.
  После подтверждённого владельцем входа выполнено только чтение настроек:
  version updates на форке **Disabled**, security updates включены.
  Это подтверждённая причина отсутствия обычных предложений обновлений.
  Полный lint выявил 24 однотипных RestrictedApi срабатывания на публичных
  inherited Builder-setters TV Provider; первичный Java source и его пример
  подтверждают публичный контракт. Добавлены два локальных SuppressLint
  только на методы записи программ; API и записываемые поля не меняются.
- **D4:** удалены неиспользуемый logging-interceptor и alias каталога.
